These Latin WOFF2 files are the same fonts used by the reference website on
port 3001: IBM Plex Sans (headings), Source Sans 3 (body), and Allura (script).
They are bundled with the application so development and production builds
do not depend on downloading fonts from Google.

The original heading sizes, weights, and letter spacing are preserved.
Each font's SIL Open Font License is included in this directory.
